# Rupiksha Project Customization Rules

## Context File Maintenance (`context.md`)

- **Ascending Date Order:** Always document new developer work logs, changes, and packages under daily date headings (`### 📅 [Month DD, YYYY]`) in chronological **ascending** order (older dates on top, newer dates appended at the bottom).
- **Daily Grouping:** Group all changes made on the same calendar day under a single date heading instead of separating them into redundant sections.
- **Detailed Bullet Points:** Break down component structures, new classes, whitelisted APIs, and removed assets as clean sub-bullets under their respective phase/task descriptor.
- **Automatic Sync:** Update this file at the end of each session or phase to ensure it remains the single source of truth for the codebase.
